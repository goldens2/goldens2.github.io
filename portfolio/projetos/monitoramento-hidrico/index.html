CONTEXTO DA PESQUISA

Do dado à pergunta

A proposta de pesquisa é acompanhar condições hídricas em alface a partir de sensores capacitivos e componentes de IoT. A visualização acima é uma demonstração independente, construída para explorar como séries de leituras poderiam ser analisadas.

Em uma aplicação experimental, seria necessário calibrar o sensor, registrar a metodologia, validar medições e considerar variáveis como tipo de substrato, temperatura e condições de cultivo.

COMO FOI CONSTRUÍDO

O que este protótipo faz

  • Gera séries temporais sintéticas em JavaScript.
  • Permite trocar cenários, períodos e limiar de referência.
  • Calcula média e quantidade de observações abaixo do limiar.
  • Exporta os valores gerados em CSV para análise posterior.
  • Funciona no GitHub Pages, sem servidor ou banco de dados.
